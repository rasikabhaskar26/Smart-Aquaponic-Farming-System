# Smart Aquaponic Farming System

## Project Description

The Smart Aquaponic Farming System is an IoT-based project designed to
improve aquaponic farming through monitoring and automation. The system
uses an ESP8266 microcontroller, sensors, a relay module, and a water
pump to monitor and control important conditions in the aquaponic setup.

## Objectives

-   Monitor important water conditions in the aquaponic system.
-   Automate water circulation using a relay-controlled pump.
-   Reduce manual monitoring and improve system efficiency.
-   Support smart and sustainable farming.

## Components Used

-   ESP8266
-   TDS Sensor
-   Relay Module
-   Water Pump
-   Power Supply
-   Aquaponic farming setup
-   Connecting wires

## Software Used

-   Arduino IDE
-   Embedded C / Arduino C

## Working

1.  The sensors collect information from the aquaponic system.
2.  The ESP8266 receives and processes the sensor readings.
3.  Based on the programmed conditions, the ESP8266 controls the water
    pump through the relay module.
4.  This helps maintain proper water circulation with less manual
    intervention.
